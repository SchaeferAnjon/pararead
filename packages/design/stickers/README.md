# 白板自带贴纸（36 张）

学习、标签、心情三套各 12 张，是画布笔记自己画的（设计页 145「卡片贴纸便签胶带」，设计稿 `design/ink-decor/src/decor.js`），
不取自任何第三方素材，以 CC0 1.0（公有领域）放出：任何人可以随意复制、修改、商用，不用署名。

- 这里的 SVG 由 `node scripts/stickers.mjs` 从设计稿生成，改贴纸改设计稿再跑；`--check` 核对两边一样。
- iPhone / iPad 用的 PNG（四倍）在 `apps/apple/CanvasNotes/Resources/Stickers/`，同一个脚本画出来。
- 名字（文件名）就是笔迹文件里贴纸行的 `k`；第一次用时拷进库里的 `附件/贴纸/<k>.svg`。
